# Licensing code, data, and outputs

This repository contains several kinds of research object. They do not all share one
licence.

## Source code

Original source code in this repository is licensed under the MIT License; see
[`LICENSE`](LICENSE).

## Documentation

Unless a file says otherwise, project-authored Markdown documentation is distributed under
the same MIT terms. Quoted or adapted third-party material retains its original terms and
attribution.

## Input data

Input datasets retain the provider's licence. They are not relicensed by this repository.
Many are not committed because of size, access conditions, or redistribution restrictions.
The authoritative per-source record is [`data_sources.md`](data_sources.md).

Examples of obligations that matter here include:

- Biodiversity Intactness Index v2.1.1 and Ookla data: CC-BY-NC-SA 4.0;
- GRIP4: Open Database Licence (ODbL);
- several GHSL, EEA, and Kummu inputs: CC-BY;
- administrative boundaries: EuroGeographics attribution conditions.

Always verify the exact version and current provider terms before redistribution.

## Figures, tables, and other derived outputs

The MIT code licence does **not** automatically apply to derived outputs. An output can
inherit attribution, non-commercial, share-alike, database, or other obligations from its
inputs. A figure or table combining sources must satisfy every applicable input licence.

Before publishing an output:

1. identify every source used directly or indirectly;
2. read its entry in `data_sources.md` and the provider's current terms;
3. include required attribution and citations;
4. apply non-commercial/share-alike or database terms where they propagate;
5. ask the project maintainers if the combined-output licence remains unclear.

The project has not adopted a blanket licence for all figures and tables. Until that is
resolved, treat committed outputs as “ask before redistribution”.

## Citation is separate from permission

A licence states what reuse is permitted; citation gives scholarly credit. Reusers should
cite both this repository and the underlying datasets named in `data_sources.md`, even when
a licence does not make citation an explicit condition.
